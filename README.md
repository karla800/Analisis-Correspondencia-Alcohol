# 🍷 Análisis de Correspondencias: Consumo de Alcohol en Estudiantes.

## 📝 Descripción
Este proyecto analiza los hábitos de consumo de alcohol en estudiantes de secundaria de las áreas de Matemáticas y Portugués, y su relación con el entorno social y familiar. Mediante el análisis de una base de datos de 382 casos y una encuesta de 33 ítems, se evaluaron aspectos como tiempo libre, convivencia, relaciones y aspectos escolares.

## 🛠️ Herramientas y Metodología
* **Lenguaje:** R (para modelado y pruebas de hipótesis).
* **Análisis Estadístico:** Pruebas de Independencia Ji-cuadrada ($\chi^2$).
* **Modelo Multivariado:** Análisis de Correspondencias Múltiples (ACM).

## 📈 Hallazgos Principales
* Se evaluaron diversas variables (zona de vivienda, actividades extracurriculares, acceso a internet, tamaño de familia, etc.), pero las pruebas Ji-cuadrada demostraron que solo el **"Sexo"** y la **"Frecuencia de salida con amigos"** tienen una dependencia estadísticamente significativa ($p < 0.05$) con el consumo de alcohol en fines de semana.
* El modelo de Análisis de Correspondencias logró explicar el **67.02% de la variabilidad total** de los datos usando únicamente dos dimensiones.
* **Perfil de bajo consumo:** Se asocia principalmente a mujeres con una baja frecuencia de salidas con amigos.
* **Perfil de alto consumo:** Se presenta con mayor frecuencia en hombres y en estudiantes que tienen una alta interacción social.
